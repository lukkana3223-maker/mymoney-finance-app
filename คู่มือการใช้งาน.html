เริ่มจัดการเงินได้ในไม่กี่ขั้นตอน

บันทึกเงินเข้าและเงินออกตามจริง แล้วแอปจะช่วยสรุปยอดคงเหลือ รายจ่ายรายเดือน บิล งบประมาณ เงินออม และหนี้ให้

ก่อนเริ่ม: แอปไม่มีรายการตัวอย่างและไม่เชื่อมบัญชีธนาคาร ต้องกรอกข้อมูลด้วยตนเอง ตัวเลขบนหน้าจอจึงอิงจากรายการที่คุณบันทึกไว้เท่านั้น

1 เริ่มต้นด้วยเงินที่มีอยู่

  1. กด เพิ่มรายการ
  2. เลือก ยอดตั้งต้น
  3. ใส่ชื่อ เช่น “เงินที่มีตอนเริ่มใช้” จำนวนเงินจริง และวันที่เริ่มใช้งาน
  4. กด บันทึก

ยอดตั้งต้นจะรวมใน “เงินคงเหลือจริง” แต่ไม่นับเป็นรายรับของเดือนนั้น เพื่อให้ยอดเริ่มตรงกับเงินที่มีอยู่

2 บันทึกรายรับและรายจ่าย

  1. กด เพิ่มรายการ แล้วเลือกรายรับหรือรายจ่าย
  2. กรอกชื่อรายการ จำนวนเงิน หมวดหมู่ และวันที่
  3. ตรวจข้อมูลแล้วกด บันทึก
บันทึกทันทีหลังรับหรือจ่ายเงิน จะช่วยให้ยอดเงินคงเหลือและสรุปของเดือนใกล้เคียงเงินจริงมากที่สุด

3 ดูหน้าหลักอย่างไร

เงินคงเหลือจริงยอดตั้งต้น + รายรับ + เงินกู้ − รายจ่าย − เงินออม − เงินชำระหนี้
รายรับ / รายจ่ายยอดรวมของเดือนปัจจุบันจากรายการที่บันทึก
สถานะเงินแจ้งเมื่อยอดคงเหลือต่ำกว่าศูนย์ เป็นศูนย์ หรือยังเป็นบวก
รายการล่าสุดตรวจชื่อ หมวดหมู่ วันที่ และยอดที่บันทึกไว้

หากยอดไม่ตรงกับเงินในบัญชี ให้ตรวจรายการที่บันทึกหรือเพิ่มยอดตั้งต้นให้ถูกต้อง

4 บิลและงบรายสัปดาห์

  • บิล: กด “เพิ่มบิล” ใส่ชื่อ ยอด และวันครบกำหนด เมื่อจ่ายแล้วกด “จ่าย” ระบบจะบันทึกรายจ่ายและนำบิลออกจากรายการค้างชำระ
  • งบรายสัปดาห์: กด “ตั้งงบ” เลือกหมวดหมู่และวงเงิน แอปเปรียบเทียบกับรายจ่ายหมวดเดียวกันตั้งแต่วันจันทร์ของสัปดาห์ปัจจุบัน
รายการจ่ายบิลจะใช้หมวดหมู่ “บิล” จึงไม่ถูกรวมในงบหมวดอื่นโดยอัตโนมัติ

5 เงินออมและหนี้

  • เงินออม: เพิ่มเป้าหมายและยอดที่ต้องการก่อน จากนั้นเพิ่มรายการ เลือก “ออมเงิน” แล้วเลือกเป้าหมาย เงินออมจะลดเงินพร้อมใช้และเพิ่มยอดสะสมของเป้าหมายนั้น
  • หนี้เดิม: กด “เพิ่มหนี้” แล้วบันทึกยอดคงค้าง เพื่อเริ่มติดตามหนี้ที่มีอยู่
  • รับเงินกู้ใหม่: เพิ่มรายการแล้วเลือก “รับเงินกู้” ระบบจะเพิ่มเงินคงเหลือและเพิ่มยอดหนี้
  • ชำระหนี้: กด “ชำระ” ข้างรายการหนี้ ใส่ยอดที่จ่าย ระบบจะลดทั้งเงินคงเหลือและยอดหนี้

6 ดูย้อนหลังและส่งออก

  1. เลื่อนลงไปที่ ประวัติรายเดือน
  2. เลือกเดือนจากช่อง “เดือน” เพื่อดูยอดและรายการของเดือนนั้น
  3. กด ส่งออก CSV เพื่อบันทึกรายการของเดือนที่เลือก เปิดดูต่อใน Excel หรือแอปตารางคำนวณได้
  4. กดปุ่มลูกศรด้านบนเพื่อดาวน์โหลดไฟล์ JSON ซึ่งเป็นข้อมูลสำรองทั้งหมด

ไฟล์ CSV ใช้ดูหรือคำนวณต่อ ส่วนไฟล์ JSON ใช้สำรองและกู้คืนข้อมูลในแอป

7 กู้คืนข้อมูลและเก็บรักษาข้อมูล

  1. กด กู้คืนข้อมูลสำรอง ที่ด้านล่างของหน้า
  2. เลือกไฟล์ JSON ที่เคยดาวน์โหลดไว้
  3. รอข้อความแจ้งว่ากู้คืนสำเร็จ

ข้อมูลเก็บอยู่ในเบราว์เซอร์ของอุปกรณ์นี้ ไม่ได้ซิงก์ข้ามเครื่อง หากเปลี่ยนโทรศัพท์หรือเบราว์เซอร์ ให้สำรองไฟล์ JSON แล้วกู้คืนบนเครื่องใหม่

อย่าลบข้อมูลเบราว์เซอร์ก่อนสำรองไฟล์ เพราะการลบข้อมูลเว็บไซต์อาจลบรายการการเงินที่บันทึกไว้ด้วย

8 ติดตั้งไว้บนหน้าจอ

  • iPhone: เปิดลิงก์แอปด้วย Safari → แชร์ → เพิ่มไปยังหน้าจอโฮม → เพิ่ม
  • Android: เปิดลิงก์แอปด้วย Chrome → “ติดตั้งแอป” หรือ “เพิ่มไปยังหน้าจอหลัก”

การติดตั้งต้องเปิดจากลิงก์เว็บไซต์ HTTPS ไม่สามารถติดตั้งจากไฟล์ที่เปิดตรงจากเครื่องได้

คู่มือแอป “เงินของฉัน” · ข้อมูลตัวอย่างไม่มีในแอป ยอดทุกส่วนคำนวณจากรายการที่ผู้ใช้บันทึก
